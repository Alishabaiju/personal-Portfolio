NLP · Text-to-Speech · Animation · Web App

Eye Blink Detection for Virtual Cursor Control

Computer Vision · OpenCV · Accessibility

Developed a hands-free virtual cursor system using real-time webcam input and eye-blink detection to help people with motor impairments navigate a computer without a traditional mouse.

Implemented facial landmark tracking and blink recognition algorithms with OpenCV to reliably translate eye blinks into mouse click actions, improving accessibility and human-computer interaction without any additional hardware.
